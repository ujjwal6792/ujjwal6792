## Currently building — Ritiflow

**Founder · Software Architect**

[Ritiflow](https://ritiflow.com) is where I am building practical operational software for businesses that need reliable technology without unnecessary infrastructure or complexity.

Its first major platform, **Ritideck**, is an offline-first field-operations system designed for environments where connectivity, device integrity, and deployment constraints are part of the problem — not edge cases.

Ritideck covers:

`field execution` · `offline sync` · `trusted devices` · `signed evidence`
`location & routing` · `attendance` · `forms` · `self-hosted deployments`

The platform is designed to run both as managed infrastructure and inside customer-controlled environments.
